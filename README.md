# CloudLab — Cloud Computing Activities

A responsive, single-page static website for a cloud-computing learning project.

## Activities
1. Cloud service deployment checklist
2. Virtual machine sizing simulator
3. Cloud security review
4. Risk register and SLA framework
5. Performance and auto-scaling simulator

## Run locally
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then save. Wait for GitHub Pages to publish the site.

## Important note
The simulators are illustrative educational demos. They do not provision real cloud infrastructure or connect to a cloud provider.
